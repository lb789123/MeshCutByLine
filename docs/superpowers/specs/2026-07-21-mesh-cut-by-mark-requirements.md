# MeshCutByMark 需求文档

## 1. 问题背景

### 1.1 现状

有一个三角形网格（mesh），其中每个三角形都有一个 **mark** 属性，表示该三角形属于哪个平面。

### 1.2 遇到的问题

由于网格存在以下问题，直接按 mark 分组提取边界会导致多边形异常：
- **非流形边**：被 3 个或更多三角形共享的边
- **孔洞**：边界不闭合

### 1.3 期望

能够从网格中提取出**简单多边形**（不自交、闭合的多边形），每个多边形对应一个平面区域。

---

## 2. 输入

### 2.1 网格数据

- **顶点**：三维坐标点集合
- **三角形**：由三个顶点组成的面
- **mark 属性**：每个三角形有一个整数 mark，表示该三角形属于哪个平面（由外部定义）

### 2.2 网格问题

网格可能包含：
- 非流形边（被 3+ 三角形共享）
- 孔洞（边界不闭合）
- 这些问题导致直接提取边界会产生异常多边形

---

## 3. 输出

### 3.1 输出内容

对每个简单多边形区域，输出：
- **原始 mark**：该区域属于哪个平面
- **新标记**：该简单多边形的唯一 ID
- **三角形列表**：该区域包含的所有三角形索引
- **边界边序列**：该区域的边界顶点索引序列，形成闭合多边形

### 3.2 输出格式

```cpp
struct splitReg {
    int mark;                    // 原始平面标记
    int newMark;                 // 新标记（简单多边形 ID）
    std::vector<int> inTris;     // 包含的三角形索引
    vcg::Point3d normal;         // 法向量（与原始 mesh face 一致）
    std::vector<int> boundlines; // 边界边的顶点索引序列
};
```

### 3.3 输出要求

1. **简单多边形**：每个输出的边界必须是简单多边形（不自交、闭合）
2. **方向一致**：边界边的方向与原始 mesh face 的方向一致
3. **完整覆盖**：所有三角形都必须被分配到某个简单多边形
4. **无重叠**：每个三角形只能属于一个简单多边形

---

## 4. 核心需求

### 4.1 区域分割

**需求**：将同一个 mark 的连通区域，分割成多个简单多边形。

**原因**：由于非流形边和孔洞的存在，同一个 mark 的区域可能不是简单多边形，需要进一步分割。

### 4.2 延长线切割

**需求**：使用延长线切割来分割区域。

**具体流程**：
1. 找到区域内的切割边（mark 不同的边、非流形边、边界边）
2. 将切割边连接成连续折线（按端点首尾相连）
3. 对每条折线，检查首尾端点：
   - 如果端点在 **mark 不同的边上** → 已在边界，不需要延长
   - 如果端点**不在** mark 不同的边上 → 从该端点**延长切割**
4. 延长切割：构造切割平面（垂直于三角形平面，包含折线方向），用平面切割区域中的所有三角形
5. 同时更新邻域三角形（共享边有交点就加点）

### 4.3 新标记机制

**需求**：用新标记记录每个简单多边形的归属。

**具体流程**：
1. 每次延长线切割后，通过拣选得到切割后的子区域
2. 每个子区域标记唯一的新标记（新1, 新2, 新3...）
3. 最终所有三角形都被标记，按新标记分组得到最终的简单多边形

---

## 5. 约束条件

### 5.1 输入约束

- 网格必须是三角形网格（每个面有且仅有 3 个顶点）
- 每个三角形必须有 mark 属性
- mark 由外部定义，本模块只读取，不负责计算

### 5.2 输出约束

- 输出的多边形必须是简单多边形（不自交、闭合）
- 边界边的方向必须与原始 mesh face 的方向一致
- 所有三角形都必须被分配到某个简单多边形
- 每个三角形只能属于一个简单多边形

### 5.3 性能约束

- 时间复杂度：O(F * C)，F 为三角形数，C 为切割边数
- 空间复杂度：O(F + E)，E 为边数

---

## 6. 验收标准

### 6.1 功能验收

1. **简单多边形**：输出的每个边界都是简单多边形（不自交、闭合）
2. **完整覆盖**：所有三角形都被分配到某个简单多边形
3. **无重叠**：每个三角形只属于一个简单多边形
4. **方向一致**：边界边的方向与原始 mesh face 的方向一致

### 6.2 测试用例

1. **简单平面**：无切割边，输出 1 个多边形
2. **两个平面相交**：有 mark 不同边，输出 2 个多边形
3. **带孔洞**：有边界边，输出 1 个多边形（带孔）
4. **非流形**：有非流形边，输出多个多边形
